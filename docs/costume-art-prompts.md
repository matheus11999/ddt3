# Prompts de arte das fantasias

Gerados pelo Codex no PC do usuário em 18/10/2026 (fundo magenta #FF00FF, depois chave para alfa). Anexar o atlas da fantasia (`public/assets/costumes/costume-<id>.png`); no deitado, anexar também uma prancha do combate das roupas e `docs/templates/prone-body.png`. Validar com `npm run verify:cosmetics`.

## Andar (`costume-<id>-walk.png`)

> Production 2D painted chibi game sprite sheet, DDTank style. Use the attached sheet as the exact character reference (top-left painting = idle pose): same design, colors, proportions, outlines and painted volume. Paint a 6-frame WALK CYCLE of this same character, 3/4 side view facing RIGHT, 3 columns x 2 rows, one full-body figure centered in each 512x512 cell with a generous empty margin: nothing crosses a cell border and nothing touches the image edge. Identical scale, identical head size and the same feet line (same bottom height) in all six frames. Order left-to-right, top-to-bottom: 1 right foot forward contact; 2 down (knees bent, body lowest); 3 passing (body highest, left leg passing); 4 left foot forward contact; 5 down; 6 passing. Legs clearly different between frames; arms swing opposite to the legs; cape/tail follow with a slight lag; the hand prop stays in the same hand. Genuine transparent background, no floor, no shadow, no text.

## Combate deitado (`costume-<id>-prone.png`)

> Production 2D painted chibi game sprite sheet, DDTank style. Same character as the attached costume sheet (exact design, colors, outlines). Paint it LYING BELLY-DOWN on the ground exactly like the game's normal combat pose shown in the top row of the combat reference: feet to the LEFT, the big head on the RIGHT raised and looking forward, chest slightly raised, legs stretched behind. The costume's own head/helmet/hat is included (the costume replaces the head). The hand prop (hammer or staff) is strapped diagonally on the BACK, hands empty. 6 frames, 3 columns x 2 rows, one figure centered in each 512x512 cell with generous margin, nothing crossing cell borders or touching the image edge, identical scale and the same ground line in every frame. Order: 1 rest (both forearms on the floor in front of the chest); 2 crawl A (right forearm reaching forward, left leg kicked back); 3 crawl B (opposite limbs); 4 charge (both empty hands raised up behind the head, as if holding something to throw); 5 throw (both arms whipped forward pointing up-right, empty hands); 6 hurt (flinch, eyes squeezed shut). Genuine transparent background, no floor, no shadow, no weapon in the hands, no text.
